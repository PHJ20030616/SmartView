# Task 5.5 — 前端面试页面 设计

> 日期：2026-08-09
> 状态：已评审（用户确认范围与语义决策）
> 关联：`develop_plan/smartview-task-plan_1.0.md` Task 5.5、`docs/interview-policy.md`

## 1. 目标

实现前端面试会话页：展示当前问题、文本回答、进度（已完成数 + 预期范围）、支持提前结束、刷新后恢复当前会话与历史问答。因后端契约不提供历史列表与结束端点，本期按用户决策**扩展后端契约**补齐这两处能力，再实现前端。

## 2. 关键决策（用户已确认）

| 决策 | 结论 |
| --- | --- |
| 历史问答恢复 | **扩展后端契约**：`InterviewSession` 增加 `answers` 历史数组，`GET/POST /api/interview-sessions` 返回 |
| 提前结束 | **新增后端端点** `POST /api/interview-sessions/{sessionId}/finish`：置 `COMPLETED` + `end_reason=USER_FINISHED_EARLY` + `ended_at`（区别于 CANCELLED=放弃不生成报告），v0.6 报告阶段据此区分 |
| 历史字段 | 历史项复用 `InterviewQuestion` schema + 回答文本/耗时/提交时间 + `AnswerEvaluation`（score/level/evaluationText） |
| 不暴露内部 | 响应 DTO 继续白名单字段，不出现 `current_stage`/`stagePlanJson`/`stageCoverageJson` 等内部字段（现有 mapper 已保证，历史项同样复用白名单） |

## 3. 契约变更（契约优先，先改后生成）

`contracts/web-api/openapi.yaml`：
- `InterviewSession` 增加可选字段 `answers: AnswerHistoryItem[]`（已回答问题历史，按提问顺序）。
- 新增 schema `AnswerHistoryItem`：`question`(InterviewQuestion 复用) + `answerText` + `durationSeconds` + `submittedAt` + `evaluation`(AnswerEvaluation 复用)。
- 新增端点 `POST /api/interview-sessions/{sessionId}/finish` → 返回 `InterviewSessionResponse`（404 会话不存在）。

后端 DTO 由 `smartview-server/pom.xml` openapi-generator 构建时生成；前端 `schema.ts` 由 `npm run generate:api` 重新生成。

## 4. 后端实现（smartview-server）

- `InterviewSessionService`：新增依赖 `InterviewAnswerMapper`、`AnswerEvaluationMapper`。
  - `getSession`：查本会话 `status=ANSWERED` 的问题（`questionOrder` 升序）+ 批量答案/评估 → 组装 `answers` 挂响应；`createSession` 返回空数组。
  - 新增 `finishSession(userId, sessionId)`：归属校验（NOT_FOUND/FORBIDDEN，防 IDOR）→ `IN_PROGRESS` 时条件 UPDATE（`WHERE id=? AND status='IN_PROGRESS'` + `version=version+1`，天然防并发）置 `COMPLETED`+`USER_FINISHED_EARLY`+`ended_at` → 已是终态则幂等返回现状。
- `InterviewSessionController`：新增 `POST /{sessionId}/finish`。
- `InterviewSessionDtoMapper`：新增 `toAnswerHistoryItem(...)` 映射。

## 5. 前端实现（smartview-web）

- 新增 `features/interview/`（api/service 分层，类型直接用生成 schema，不手写重复 DTO）：
  - `interviewApi.ts`：`createInterviewSessionApi` / `getInterviewSessionApi` / `submitAnswerApi` / `finishInterviewSessionApi`（沿用 `ApiResponseWrapper` + `extractData`）。
  - `interviewService.ts`：创建/恢复/提交/提前结束；生成 `requestId` 幂等 UUID、`durationSeconds`；409/404 语义化错误。
  - `index.ts` barrel。
- 新增 `pages/interview/InterviewSessionPage.tsx`（替换占位页，路由不变 `/interview/session`）：
  - 进入：URL 有 `sessionId` → `GET` 恢复；无 → 用 `profileId`+`roleDirection` 创建会话并 `replace` URL 补 `sessionId`。
  - 状态：`loading` / `active` / `ended` / `error`。
  - active：头部（方向标签 + 进度"已完成 X 题 · 预计 Y~Z 题" + 结束面试按钮）→ 历史问答列表（问题/回答/评估得分+等级+评语）→ 当前问题卡片 + 文本域 + 提交按钮。
  - 提交：提交中禁用；成功追加历史并推进 `currentQuestion`/进度；`sessionStatus` 非 IN_PROGRESS 或 `nextQuestion` 空 → `ended`；失败 409 用 `GET` 对账，其他提示重试。
  - 提前结束：`Modal.confirm` → 调 `finish` → `ended`；刷新后终端态直接 `ended`。
  - ended：面板 + "返回首页"/"再来一次"（v0.6 才加报告入口）。
  - 不读取/展示任何内部字段。
- `router.tsx` 替换占位页；`global.css` 增加 `.session-*` / `.qa-*` 类。
